Project Overview

From Historical Breaks to Predictive Maintenance

The project builds a complete machine learning and MLOps workflow for predicting water main failures in the Kitchener-Waterloo region of Canada. Using characteristics such as pipe material, diameter, age and historical break information, the model estimates whether a pipe is likely to break within the next five years.

The Data Challenge

How do you train a classifier when the dataset is mostly pipes that already failed?

The original Kitchener-Waterloo dataset contains historical water main breaks. However, it does not provide a clean set of confirmed negative examples representing pipes that did not break. To solve this problem, the project creates training examples using historical time snapshots.

Label = 0
2008 Pipe snapshot
2011 No break within horizon

→ No break recorded in the 5-year window after the snapshot.

Label = 1
2014 Pipe snapshot
2017 Break occurs

→ A break is recorded inside the 5-year window after the snapshot.

Temporal Snapshot Labeling

Historical snapshots are generated before and after recorded failures to construct positive and negative training examples while respecting temporal information — no future data ever leaks into a snapshot's features.

Every transformed dataset is fingerprinted with a SHA-256 hash and logged alongside each training run, ensuring full reproducibility between experiments.

Machine Learning Models

Multiple Models. One Champion.

Several algorithms are benchmarked on the same temporally-split data so the strongest candidate can be selected objectively.

LR

Logistic Regression

A fast, interpretable linear baseline that estimates break probability directly from pipe features.

RF

Random Forest

Ensemble of decision trees capable of capturing complex non-linear relationships.

XGB

XGBoost

Gradient boosting model optimized for strong tabular prediction performance.

SVM

SVM

Finds the optimal boundary between at-risk and low-risk pipes in feature space.

MLP

MLP Neural Network

A small feed-forward network that learns non-linear interactions between pipe attributes.

ST

Stacking Ensemble

Combines predictions from multiple models using a meta-model for a stronger final estimate.

Hyperparameter Optimization

Optuna searches for optimal model configurations automatically

Instead of hand-tuning parameters, an Optuna study runs dozens of trials per model, maximizing validation PR-AUC while penalizing configurations that overfit the training data.

Automatic Model Selection

The Model Gate

After training, models are not automatically deployed. They must pass a validation gate.

  • Compares candidate models trained in the same experiment
  • Uses PR-AUC as the primary selection metric
  • Checks generalization performance on a held-out temporal split
  • Detects potential overfitting between train and test scores
  • Rejects models that do not satisfy quality rules
  • Selects the best surviving model as the champion

Liveness check and current MLflow tracking URI.

GET /model-info

Returns information about the current champion model.

POST /predict
